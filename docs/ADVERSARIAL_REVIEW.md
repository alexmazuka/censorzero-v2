# Adversarial self-review

The value of this project is not the conclusion but the *provability* of the
conclusion. This document maps every failure mode of the v1 study to the v2
mechanism that removes it, and states honestly where v2 is still limited.

## v1 anti-patterns → v2 mechanism

| # | v1 failure | v2 mechanism | Where |
|---|-----------|--------------|-------|
| 1 | Mixed classifier generations in one table (P0 new, P1/P2 frozen) | One `features.py` / `classification.py` applied identically to every article of every outlet/period; versions stamped per row; CI reproduces from raw | `src/censorzero/features.py`, `classification.py` |
| 2 | Substring source matching (`сбу`⊂`Фейсбуці`, `ова`⊂`Калашнікова`) | Word-boundary regex with Ukrainian lookarounds only; a test asserts every v1 substring bug does **not** fire | `text_norm.py`, `tests/test_classification.py` |
| 3 | No first-person surnames; foreign bodies counted as parket | Registry includes Зеленський et al.; `foreign_official` flag excludes NATO/EU/G7/foreign ministries/МЗС РФ from parket | `data/registry/entities_v2.json`, tests |
| 4 | Control 0% parket *by construction* (numeric UP slugs) | Officialness classified from article **text**, not slug; identical code path for treatment and control (tested) | `classification.py`, `features.py` |
| 5 | Data committed without generating code (`censorship_test.json`) | Every published number is regenerated by `make all` from committed raw; CI forbids drift; no committed metric lacks a producer | `.github/workflows/verify.yml` |
| 6 | Post-hoc scripts; circular run-order | Single entrypoint `python -m censorzero.pipeline`; raw and derived in separate commits so lineage is self-consistent | `pipeline.py`, `manifest.py` |
| 7 | Absolute local paths; gitignored "main" files | CI greps for machine-absolute home-directory prefixes (the ones under `Users` / `home`); repo-relative paths only; committed snapshot is the source of truth | hygiene job |
| 8 | Hardcoded numbers in HTML diverging from JSON | HTML carries zero study digits; all injected from `figures.json` at runtime; CI enforces via `check_no_hardcoded_numbers.py` | hygiene job |
| 9 | Sources truncated to 5; nondeterministic order | Full source list persisted (no `[:N]`); sorted iteration everywhere; fixed seed | `source_extraction.py`, `stats.py` |
| 10 | Three pairwise tests, no correction, no effect size | Holm across the 6-test family; Cohen's h + 95% bootstrap CI on every contrast | `stats.py`, `stages/processed.py` |

## Where v2 is still limited (stated, not hidden)

- **Proxy, not IMI's method.** IMI hand-codes ~100 items twice a year; we scan
  the full stream lexically. IMI publishes no numeric threshold. Agreement is
  measured by the gold standard, not assumed.
- **Bodies come from the Web Archive.** Ukrinform's 2023 weekly sitemaps have
  expired from the live web, and the origin IP-throttles bulk crawling, so
  article bodies are fetched from Wayback snapshots (≈97% coverage for
  Ukrinform). This is more reproducible (stable, timestamped) but archive
  coverage is not 100%; the uncovered share is published and the fetch-failure
  report is committed.
- **Суспільне is a sample.** Deterministic even-stride sample of ~12k of ~170k
  discovered URLs (Deviation logged). It is a *secondary, descriptive* control.
- **Byte-exact scope.** The published artifact `figures.json` (rates, bootstrap
  p-values, counts, arcsin-based Cohen's h at 6 dp) and README are gated
  byte-for-byte in CI on a fixed CPU architecture. The logistic-regression
  *companion* uses an iterative MLE whose trailing digits are not bit-stable
  across platforms; it is reported in `data/processed/metrics.json` but not
  byte-gated. Rates and bootstrap p-values use only integer counts and
  fixed-order IEEE arithmetic and are exactly portable.
- **One person holds the COI** and wrote the codebook. The codebook is
  committed before annotation; the LLM annotator is blind to period/outlet; a
  human validates a subsample with published Cohen's κ.
- **Collection is a long-running background process.** Until it completes the
  published figures are marked preliminary on the site; the apparatus, tests,
  and CI are complete and green regardless.

## What would falsify our reading

If, once collection completes and recall stability is confirmed, the
standardized parket rate in P1 significantly exceeds both P0 and P2 (Holm
p<0.05, |h|≥0.2) in both ATO scenarios, the data would be *consistent* with
IMI's implied pattern. The preregistered decision rule commits us to report
that outcome exactly as found.
